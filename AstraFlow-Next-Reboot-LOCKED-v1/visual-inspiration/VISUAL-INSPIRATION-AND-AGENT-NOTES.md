# AstraFlow — Creative Visual Inspiration

These are **AI-generated visual studies**, not a shipped UI, accurate screenshot of Next.js, executable design, or technical specification. Individual crops retain the original limited resolution; use the full concept boards for surrounding visual context.

## Non-negotiable boundaries

- Preserve **AstraFlow's authentic canonical logo geometry** from the design-reference master SVG; the logos generated in the images are visual approximations and **must not** be traced or reused as identity assets.
- Preserve the warm ivory / deep forest green / vermilion orange identity, while testing accessible contrast and optical alignment.
- The old dark rectangular dashboards and tilted three-card hero placeholders are not targets; create deeply interactive, state-driven bespoke compositions.
- Preserve truthful current product facts from the actual AstraFlow docs/source and verified NuGet packages. Any version text, code snippets, statistics, package descriptions and claims visible in AI images are not verified and must not be copied without checking.
- Visual references are **art direction**, not literal final layout or approved pixel-perfect output. The production solution must be responsive, semantic, keyboard accessible, screen-reader usable, reduced-motion aware, performant and SEO-ready.

## Execution contract for Antigravity

- Read `design-reference/AstraFlow-Creative-Rebuild-Pass-03/AGENT-START-HERE.md` and `SCENE-REPLACEMENT-MAP.md` first.
- Start with **Packages hero + Composer** and **Home Flow Atlas**. Produce actual React components, not another static gallery.
- Use official Hairline figures as prototyping references; create custom AstraFlow-specific figures or SVG + Motion where justified. Importing a stock figure alone is not completion.
- Build a typed, single-source-of-truth interaction state linking selected stages/packages to geometry, code, explanatory copy and transitions.
- Record mouse, keyboard, touch, rapid-switching and reduced-motion behavior for each experience, plus Desktop/Mobile captures.
- Show before/after pairs with visibly **different** compositions for each replaced section, and enumerate old -> new component file paths.
- Treat these images as **creative stimulus**. Iterate beyond them when needed to improve product meaning, accessibility, responsiveness and implementation feasibility.
