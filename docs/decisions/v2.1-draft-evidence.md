## Follow-up hardening

The generator now rejects file-local mapping types and preserves the `this` modifier on extension methods. Both defects were reproduced with failing compiler tests before fixing. Additional tests cover keyword identifiers, separate pairs, nullable destinations and missing types. With stable SDK 10.0.400, `dotnet test tests/AstraFlow.Generators.Tests/AstraFlow.Generators.Tests.csproj -c Release --no-restore /m:1 /p:UseSharedCompilation=false` passed 23 tests.

The EF Core test dependency chain resolved `Microsoft.EntityFrameworkCore.Sqlite` 10.0.2 → `SQLitePCLRaw.bundle_e_sqlite3` 2.1.11 → `SQLitePCLRaw.lib.e_sqlite3` 2.1.11. A runtime test confirmed SQLite 3.49.1 before the change. The test project now directly references bundle 2.1.12; its resolved bundle, provider and native library are 2.1.12, and all seven EF tests pass, including a check that the loaded SQLite is at least 3.50.2. The [advisory](https://github.com/advisories/GHSA-2m69-gcr7-jv3q) lists versions through 2.1.11 as affected; the [upstream maintenance release](https://github.com/ericsink/SQLitePCL.raw/releases/tag/v2.1.12) identifies its updated SQLite dependency. This override is test-only and does not change a public package dependency. Recheck the full solution restore and dependency audit before release.
