A targeted creative supersession of the existing AstraFlow Motion Craft Pass 02. ## Use

Copy this folder into your website repo at `design-reference/AstraFlow-Creative-Rebuild-Directive/`.

Send the full contents of `AGENT-SHORT-KICKOFF.md` to Antigravity, or ask it to read both files and execute. The large `CREATIVE-REBUILD-AUTHORIZATION.md` is the binding replacement map, creative scope, engineering contract and acceptance gate.

Earlier instructions directed the agent to *preserve* v12 compositions. That conflicted with the new request to *replace them*. This supersedes that conflict: brand is protected, presentation is not.
