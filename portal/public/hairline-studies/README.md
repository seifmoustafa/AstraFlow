# AstraFlow Bespoke Hairline Figures

This directory contains the original, bespoke Hairline figures developed per **CREATIVE-REBUILD-AUTHORIZATION.md** § 61–76 for the AstraFlow Radical Creative Rebuild:

1. **`hairline-astraflow-route.html`** (`astraflow-route.js`): The Calibrated Pipeline Conduit
2. **`hairline-astraflow-assembly.html`** (`astraflow-assembly.js`): The Interlocking Architectural Assembly
3. **`hairline-astraflow-branchwork.html`** (`astraflow-branchwork.js`): The Open Contribution Circuit
4. **`hairline-astraflow-version-spine.html`** (`astraflow-version-spine.js`): The Mechanical Version Folio

All four figures:
- Strictly follow the ten rules of Hairline (`rules.md`).
- Pass `validate.mjs` with code 0 (`ok`).
- Provide standalone tour playback, intensity controls, and accessible readouts.
- Are integrated into the Next.js portal via `@/components/motion/BespokeHairlineFigures` and mounted on `/__craft`.
