# AstraFlow Craft Pass 02 — Review & Sign-off

## First: establish what really exists

- [ ] The agent inspected **actual Next.js app** and captured before-state screenshots/video, not only the source HTML.
- [ ] Current installed Hairline version and imports are shown; downloaded dependencies alone do not count.
- [ ] Current Motion usage and actual animations are enumerated by component.
- [ ] User-facing baseline, logo variants, palette, typography, content and routes are preserved.

## Signature interactions

- [ ] Home Hero A/headline stable; one signal on exact approved path; pause/visibility/reduced motion work.
- [ ] Home Flow Explorer 3 capabilities × 4 stages; active trace, text, code and counter always in sync.
- [ ] Flow stage switching can be interrupted repeatedly without stale UI.
- [ ] Architecture Assembly is one continuous *spatial* 3-layer composition, not 3 boxes on separate cards.
- [ ] Packages uses real selectable modules, assembled composition, accurate install commands; no fake dependencies.
- [ ] Community uses four real links connected by visually highlighted paths; focus and hover have equivalent effect.
- [ ] Changelog release rail highlights actual selected record, expands smoothly, history and publication status truthful.
- [ ] Guides progression is usable via touch/keyboard; selected state and content synchronize.
- [ ] Docs search, keyboard navigation, TOC and code copy work without heavy decorative animation.
- [ ] Navigation, focus, press and hover are intentionally polished and consistent.

## General quality

- [ ] Each component has a resting state that looks as good as its animated state.
- [ ] No auto-running figure collection; passive animation is limited to existing Home signal and rare functional indication.
- [ ] No layout shifts, text clipping, controls under overlays, hydration errors or console warnings.
- [ ] All responsive widths 320/390/768/1024/1440/1920 checked on build, not dev only.
- [ ] Reduced motion still conveys every state; no required user action needs hover.
- [ ] 200% browser zoom and keyboard Tab/Enter/Escape tested.
- [ ] No global Lenis, GSAP, Three.js, Rive, GSAP + Motion double-orchestration or other unreviewed dependencies.
- [ ] Lighthouse, axe and production build commands + results attached.
- [ ] Real-user CWV thresholds are production targets, not false local acceptance claims.
- [ ] Clear before/after screenshots and **video evidence** for Flow, Stack and Community.

## What is explicitly NOT sign-off

- No change apart from `transition: 300ms`, `whileHover` on all cards, adding a generic Hairline widget, or repeating the same hero with new graphics.
- No claim to have created a custom Hairline figure when only a plain SVG was copied.
- No claim of 60 fps, SEO improvement, or 95% quality based solely on a static screenshot.

## Review order

1. Flow Explorer: first demo video, focus/keyboard test, code correctness.
2. Packages Assembly: add/remove test with install commands, video.
3. Community Network: focus/hover/touch and real links.
4. Home Architecture / Guides / Changelog / Docs supporting motion.
5. Global consistency, mobile, reduced motion, accessibility, production performance.
