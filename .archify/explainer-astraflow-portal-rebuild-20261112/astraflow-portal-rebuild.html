How does the rebuilt AstraFlow portal preserve Warm Forest while upgrading every interactive scene?

Long image

A

Answer

The new portal/ application isolates the locked Warm Forest global shell (SiteHeader, SiteFooter, typography, and #f7f3eb page surfaces) from eight state-driven interactive instruments powered by repository data and shared Hairline isometric geometry.

  1. Every route renders statically from real .csproj, docs/**/*.md, and CHANGELOG.md files into 80 pages (244 KB JS transfer).
  2. Page heroes across all six sections keep Warm Ivory #f7f3eb backgrounds, Deep Forest #082c26 ink, and Signal Orange #f25e3b accents.
  3. Static placeholder cards and rotated sheets are replaced inside dedicated interactive components (src/components/scenes/*) backed by real React state.
  4. Full Playwright verification (57 passed, 1 intentional mobile zoom skip, 0 critical/serious/moderate WCAG 2.2 AA violations) and 60 passing .NET tests confirm release readiness.
