## HAIRLINE / MOTION — DEMONSTRATE REAL USE, NOT DEPENDENCY INSTALLATION

You already have Hairline skills available. Inspect the current official Hairline and Motion APIs and installed project dependencies. Use the applicable `hairline-create` workflow to explore ORIGINAL AstraFlow-specific figures where useful. A generated HTML study is not completed integration: adapt/refine as maintainable React/TypeScript, connect it to actual state, render it in the real route, and verify it.

For each scene choose the smallest correct engine:

- Authored SVG + Motion for precise request paths, connected nodes, progress and bespoke accessible diagrams.
- CSS + Motion layout/shared element transitions for regular UI state changes.

Animation must not convey essential information exclusively. Reduced-motion users get complete, attractive static states.
